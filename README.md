# ANALIZE — исследовательские видеоэссе и расследования

**Единая база проекта:** зарубежные фильмы и сериалы, книги, резонансные реальные дела в США и других странах (без российских кейсов по умолчанию). Язык выпусков — русский, ориентир — русскоязычная аудитория. Не сводить канал к психологии или true crime: исследовать факты, хронологию, экономику, институции, профессии, решения, мотивы, социальную среду и связи с другими историями.

## Идентичность
- Не книжный пересказ, не конспект сериала, не пересказ новостей и не набор «психологических» клише.
- Каждый выпуск начинается с **проверяемой аномалии/противоречия**, затем последовательно исследует альтернативные объяснения, заканчивает честным результатом.
- Интерес возникает из материала, не из крикливой упаковки, вопросительных лесенок или ложной интриги.
- Исследование должно давать зрителю наблюдения, факты и аргументы, которых он не знал, даже если знает исходную историю.
- Видео можно собрать из простых фрагментов с разрешённым использованием: сценарий и голос являются главным продуктом. Права на фрагменты и цитирование проверять отдельно.

## Правила памяти
- Прямые решения пользователя о темах сохранять в TOPIC_BACKLOG с датой, приоритетом и формулировкой.
- Без прямого решения новые варианты только **ГИПОТЕЗА**.
- Не заменять подтверждённый факт красивой интерпретацией.
- Отмечать изменение подхода, результат проверки, источник и дату.
- Рукописные фильтры [Ogorod](https://github.com/aafanasevaannaz-cyber/Ogorod) использовать как **ориентир борьбы с шаблонностью**, не переносить персонажей, канон книги и художественные технические квоты.
